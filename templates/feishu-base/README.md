# 简填飞书模板

## 文件

[简填求职追踪模板.xlsx](%E7%AE%80%E5%A1%AB%E6%B1%82%E8%81%8C%E8%BF%BD%E8%B8%AA%E6%A8%A1%E6%9D%BF.xlsx)
来自零记录的飞书 Base：

- `✅秋招投递表`
- `✅任务管理`
- `数据表`

每张表只有表头，没有公司记录、邮件、招聘链接或个人资料。

## 使用

1. 下载 XLSX。
2. 在飞书云空间选择“导入”，目标类型选择“多维表格”。
3. 将实际使用的投递表 Table ID 填入简填设置。
4. 创建飞书自建应用，将 Base 授权给该应用。
5. 在简填设置中填写 App ID、App Secret、Base Token 和 Table ID。

## 字段核对

XLSX 无法完整保留飞书 Base 的单选、关联和公式语义。导入后应确认：

- `父记录`：关联到当前投递表。
- `是否巡检`：单选，选项为 `是`、`否`。
- `Cookie状态`：单选，选项为 `生效中`、`已过期`、`读取失败`、`未配置`。
- `Cookie最近检测`：日期时间。
- `开始日期`、`完成时间`：日期时间。
- `进展`：单选，至少包含 `待投递`、`已投递`、`初筛`、`待笔试`、`已笔试`、
  `待面试`、`已挂`、`还没开始`。
- `待办状态`：单选，选项为 `待办`、`已完成`、`已忽略`。
- `任务描述`：公式 `CONCATENATE([公司],"-",[岗位],"-",[进展])`。

其余文本字段：

- `公司`
- `岗位`
- `最新进展记录`
- `note`
- `测评链接`
- `ddl`
- `链接`
