# Security Policy

## Reporting

Please use GitHub private vulnerability reporting when available. Do not post credentials, API keys, resumes, personal information, or working exploit details in public issues.

Include:

- Affected version.
- Reproduction steps using synthetic data.
- Expected and actual behavior.
- Impact assessment.

## Scope

Security reports may cover:

- Exposure of locally stored profile data or API keys.
- Unintended transmission of personal values.
- Cross-origin or iframe handling problems.
- Unsafe DOM interaction on recruitment websites.

The extension never needs users to share account passwords or authentication cookies with maintainers.
