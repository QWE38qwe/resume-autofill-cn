## 详细说明

简填是一款本地优先的网申资料管理与自动填表工具。

- 管理个人资料、教育、实习、项目、技能、证书和多个简历版本
- 在用户点击后扫描当前招聘页面并填写匹配字段
- 支持补充填写，默认不覆盖网页中已有内容
- 支持头像和常见重复经历控件
- 本地记录网申历史
- 可选连接用户自己的 AI API 做字段语义映射
- 可选安装本地桥接，将招聘邮件待办和投递进展同步到用户自己的飞书 Base

扩展不会自动点击保存、提交或投递。所有填写结果都需要用户检查并自行提交。
扩展不包含广告、遥测或维护者运营的云端数据服务。

## 单一用途

帮助求职者在本地管理网申资料，并在用户明确操作时把这些资料填写到招聘网站表单。
邮件待办和飞书同步是同一求职申请管理流程中的可选辅助能力。

## 权限说明

### `storage`

在当前浏览器配置文件中保存用户主动录入的简历资料、规则、设置和网申历史。

### `activeTab`

仅在用户点击扫描或填写时访问当前招聘页面。

### `scripting`

在用户触发填写时操作当前页面；在用户触发“连接并验证”时，从指定招聘站登录标签页
读取该站点的可见状态和 Web Storage。

### `nativeMessaging`

连接用户可选安装的开源本地桥接，用于 IMAP 邮件读取、招聘站巡检和写入用户自己的
飞书 Base。未安装桥接时，资料管理和自动填表仍可使用。

### `alarms`

按照用户配置的间隔唤醒邮件同步和投递进展巡检。

### `cookies`

只有用户在投递进展页点击“连接并验证”时，才读取所选招聘站点的 Cookie，并发送给
本机 Native Host 加密保存。不会读取 Chrome 密码、验证码或其他站点 Cookie。

### 所有 HTTP / HTTPS 网站

招聘系统域名数量多且持续变化，无法维护完整静态白名单。内容脚本用于识别网页表单，
但只有用户打开扩展并点击扫描或填写时才会使用本地简历值；不会自动提交表单。

### `https://api.deepseek.com/*`

支持用户自行配置的 DeepSeek 兼容 API。字段映射仅发送网页字段元数据，不发送个人
资料值；用户主动执行简历解析时除外，界面和隐私政策会明确提示。

## 数据披露

会处理：

- 身份与联系信息：用户主动录入，本地保存，用于填表
- 职业与教育信息：用户主动录入，本地保存，用于填表
- 网站内容：招聘表单字段名称和控件信息，用于字段匹配
- 身份验证信息：用户主动配置的 API Key、邮箱授权码、飞书 Secret 和招聘站会话

不会：

- 向维护者服务器上传数据
- 出售或用于广告
- 用于与产品单一用途无关的信用、保险、借贷或广告画像
- 把招聘站会话放入 Git 或 Chrome Sync

## 发布包

运行：

```bash
./scripts/build-store-package.sh
```

ZIP 只包含扩展运行文件、图标和第三方前端依赖，不包含：

- Native Host 源码和本地安装配置
- `.env`、API Key、邮箱授权码或飞书 Secret
- 数据库、招聘站登录态或调试日志
- 测试夹具和内部交接文档
