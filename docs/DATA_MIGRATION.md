# JSON 数据迁移

简填支持将当前设备中的有效扩展数据导出为 JSON 文件，并在另一台设备导入。

## 导出

进入“设置 -> 数据迁移”，点击“导出 JSON”。文件包含个人资料、教育与项目经历、
简历版本、头像、简历附件、填写历史、邮件记录和本地设置。

JSON 未加密。请保存在可信设备中，不要上传到公开网盘或发送给无关人员。

## 导入

1. 在新设备安装简填。
2. 进入“设置 -> 数据迁移”并点击“导入 JSON”。
3. 选择此前导出的文件并确认覆盖。

覆盖前会自动下载当前设备的数据回滚文件。导入后页面会刷新，并重新调度邮件任务。

## 不迁移

- 临时标签页和运行状态。
- AI 字段映射缓存。
- Native Host 保存的招聘网站 Cookie、密钥和 SQLite 数据库。
- 已停用的旧版飞书云同步配置。

招聘网站登录态需要在新设备重新连接和验证。
