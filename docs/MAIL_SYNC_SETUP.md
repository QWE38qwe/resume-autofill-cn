# 邮件待办本地同步

邮件待办由扩展通过本地 Native Host 读取 IMAP 邮箱，并使用配置的 AI 模型补全公司、分类、DDL 和任务链接。邮件内容只保存在本机，不写入任何外部表格。

## 配置

1. 安装本地桥接：Windows 执行 `native-host/install-windows.ps1`，macOS/Linux 执行 `native-host/install.sh`。
2. 在扩展“设置 → 邮件待办”填写邮箱地址、客户端授权码、IMAP 主机和端口。
3. 在“AI 模型”中配置至少一个 OpenAI-compatible 模型。
4. 点击“测试连接”，再点击“立即同步”。

## 本地任务中心

- 看板默认展示任务，可切换到月历查看在线测评、AI 面试和面试邀约。
- 公司名称可直接编辑，修正会在本机记忆并用于后续相同原始名称。
- 任务状态、完成时间、任务备注和日期备注均保存在 `chrome.storage.local`。
- 同一任务通过规范化链接或“公司 + 类型 + 岗位 + DDL”去重，重复催促邮件不会重复展示。
- 历史邮件最多保留 300 条；日期备注不随历史清理。

## 隐私与故障排查

邮件正文仅用于本次分类和信息抽取；模型只能返回结构化字段。公司无法可靠识别时会进入“公司待修正”，不会自动生成公司名称。

若同步失败，请先确认邮箱授权码、IMAP 主机和 AI 配置，再点击“重新识别公司”。所有数据和配置均可通过设置页 JSON 备份与恢复。
